# Process overview

My first idea was a general Vue course. In `IDEA.md`, I narrowed it to “Vue in the Wild” because a broad course could become twelve weeks of documentation summaries ([40feed1](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-u7663394/commit/40feed1)). I wanted students to understand how a small interface grows into an application someone else can maintain. This gave the agent a clearer direction: each week needed a reason to exist and something students could build.

I chose Vue 2 → Vue 3 → Vue 3 + TypeScript so students could compare solutions to familiar problems. Vue 2 appears as legacy maintenance, rather than advice for a new production system. The article reader introduces components, routing and shared state. The editorial dashboard revisits those responsibilities with modern Vue. The consultation app adds typed data and harder failure cases. The question of who owns the data connects them, so TypeScript has a purpose beyond learning another syntax.

I wanted these decisions to survive edits across many pages, so they became course-specific rules in `CLAUDE.md` ([3b9859d](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-u7663394/commit/3b9859d)). They fix the three phases, require a distinct question and build each week, keep the second assessment in JavaScript, preserve SlopU branding and make the consultation project a simulation. They limit invention while leaving room to improve explanations.

Assessment readiness was especially important to me. Checking the sequence once would not protect it from later changes. The original assignment tests were already committed before implementation ([c8c610d](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-u7663394/commit/c8c610d)). The added `spec/` checks protect twelve dated weeks, the phase order, assessment weights totalling 100%, and linked decks. Readiness checks compare both lecture and studio dates with deadlines. An independent tool list prevents the agent from making a check pass by deleting a requirement. The same teaching information appears in assessment briefs, so students can use it too ([9ff9de8](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-u7663394/commit/9ff9de8)). The agent tested the checks with deliberate faults, including late teaching and missing deck links, and restored the output afterwards.

I deliberately left interest, voice and teaching coherence to human judgement. Different titles cannot prove that two weeks teach different things. My review instructions therefore asked for non-adjacent weeks and assessments to be read like a prospective student would. I also treated the website itself as evidence of the frontend care the course teaches.

For the final redesign, I wanted the interface to explain the course. Slop gold remains the university identity, while Vue green shows phases, state ownership and actions. The week map, studios and assessments use different layouts because they answer different student questions. Icons identify a real tool, action or relationship. These rules entered `CLAUDE.md` with the implementation ([edbca4e](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-u7663394/commit/edbca4e)).

The browser review shows why passing a build was not enough. Earlier inspection found an overflowing phone code block and a Next button that did not respond to Space ([58687a8](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-u7663394/commit/58687a8)). The redesign review then found an assessment grid still limited by the prose width, and a decorative CSS slash being announced as part of headings. I fixed the shared rules instead of hiding either problem. A fresh sweep covered all 48 authored routes at both marking sizes, with no overflow, console error, failed response or missing page surface. I also checked the mobile menu, dark theme and one-action-per-key deck controls. The final local checks passed, including `pnpm check` and `pnpm check:evidence`. This gave me evidence for accepting the agent’s output, while leaving the judgement of whether the semester feels worth taking to me.
