# Shared State with Vuex

Week 07 · Vue 2

What should happen everywhere when the reader logs out?

---

## The fault on the desk

The header still displays a name after the account page logs out. The saved list has another copy of the user. Three correct components have produced one inconsistent application.

---

## Follow the ownership

**Action performs request**

↓

**Mutation records result**

↓

**All subscribers update**

---

## Read this seam

```js
const account = {
  namespaced: true,
  state: () => ({ user: null }),
  mutations: {
    setUser(state, user) { state.user = user }
  },
  actions: {
    logout({ commit }) { commit('setUser', null) }
  }
}
```

---

## Make the failure visible

Log in as one fixture user, save an article, log out, then log in as a different user. The second user must not inherit the first collection.
